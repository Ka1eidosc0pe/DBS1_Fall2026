Featured project

DoF.me

An AI-powered soccer sporting director simulator.

A full-stack soccer simulation game. Real soccer data is ingested through a provider abstraction layer, normalizing club and player data into canonical records with provenance tracking, refresh workflows and database-backed persistence. AI-generated narrative, powered by the OpenAI API, makes each career feel dynamic and immersive. It is covered by Jest, React Testing Library and Playwright.

  • Next.js
  • TypeScript
  • Supabase
  • Tailwind CSS
  • Vercel
  • OpenAI API
  • Jest
  • React Testing Library
  • Playwright
  1. Provider abstraction layer
  2. Normalization
  3. Canonical records with provenance tracking
  4. Database-backed persistence (Supabase), with refresh workflows looping back to the provider layer
  5. Records feed AI narrative (OpenAI API), then gameplay
  6. Testing with Jest, React Testing Library and Playwright
